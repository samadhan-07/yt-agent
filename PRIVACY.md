# Privacy Policy for yt-agent

yt-agent is a personal automation tool that uploads videos to the owner's own YouTube channel.

- **What it accesses:** only the `youtube.upload` permission on the owner's own Google account, used solely to upload videos the tool generates.
- **What it stores:** an OAuth refresh token, kept as an encrypted GitHub Actions secret in the owner's own repository. A list of past video titles and IDs is kept in the repository to avoid repeating topics.
- **What it shares:** nothing. No data is sold, shared with third parties, or used for advertising.
- **Other users:** the app is not offered to anyone else.
- **Revoking access:** the owner can remove access at any time at https://myaccount.google.com/permissions.

Contact: use the issue tracker of this repository.
